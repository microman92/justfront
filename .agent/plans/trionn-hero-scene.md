# Trionn hero scene continuity

## Цель
Повысить точность локальной WebGL-сцены: убрать электрический штрих, сделать стеклянную вращающуюся монограмму, многослойный распад при прокрутке, чертёж и осколки на About, сборку на Vision.

## Текущее состояние
Исходное состояние до этой работы: Hero, About и Vision использовали отдельные экземпляры `OrbitCanvas`; Hero распадался на небольшое число треугольников, а при удержании появлялась электрическая дуга.

## Ограничения
Работать только в `_website-cloner`; родительский portfolio не менять. Сохранить рабочий Next.js проект, DOM-контент, доступность и reduced motion. Не загружать тяжёлые 3D-модели; ограничить DPR и освобождать ресурсы.

## Предлагаемое решение
Снять кадры Trionn при реальной прокрутке и обратном движении. Построить единое состояние сцены от глобальной позиции прокрутки и передать его в один закреплённый canvas для Hero/About/Vision. Геометрию разделить на существенно большее число полупрозрачных фрагментов с контурным каркасом, материал и вращение приблизить к источнику. Удалить яркую дугу полностью.

`src/components/sites/trionn/hero-experience.tsx`, `orbit-canvas.tsx`, `intro-scenes.tsx`, при необходимости `src/app/globals.css`, `TASKS.md`. Это изолированная копия, не основной portfolio.

## Проверка
Сравнение source/local на desktop 1920×907 и mobile 390×844, прямой и обратный scroll; Chrome DevTools console и screenshots; Playwright для последовательности; `npm run check`.

## Ход выполнения
Сняты и сопоставлены состояния scrollY 0, 255, 764, 1359, 1955, 2223. Локально сделан один sticky canvas, многосоставной распад, тёмный каркас и обратная сборка. Desktop/mobile/reduced motion проверены; `npm run check` прошёл. Playwright подтвердил закрепление canvas при прокрутке 0 → 760 → 2000 → 760 → 0 без потери сцены и без горизонтального переполнения.

## Решения
Источник подтвердил один закреплённый canvas. Поэтому три локальных canvas заменены одним sticky canvas, который остаётся активным до конца Vision. Для тёмного стекла используется `MeshPhysicalMaterial` с transmission; 3D-осколки процедурные.

## Неожиданности и отклонения
Исходный canvas закреплён на `y=0` дольше Hero; прежняя структура обрывала сцену на границе секций. Множество ярких осколков ухудшало сходство: материал осколков затемнён после визуального сравнения.

## Результат
Яркая дуга удалена; знак медленно вращается и при прокрутке распадается на многочисленные осколки, оставляя каркас на About, затем собирается на Vision. При обратной прокрутке состояние восстанавливается. На mobile нет горизонтального переполнения; режим reduced motion оставляет статичный знак. Сходство с Trionn улучшено, но исходные шейдер, точная модель и траектории фрагментов недоступны: это процедурная интерпретация, не покадровое 1:1 совпадение.
