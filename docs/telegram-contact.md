# Заявки в Telegram

1. Создайте бота через [BotFather](https://t.me/BotFather) и сохраните его токен.
2. Создайте в корне проекта файл `.env.local` по примеру `.env.example` и заполните `TELEGRAM_BOT_TOKEN`. Токен храните только в настройках сервера, не публикуйте его и не отправляйте в переписке.
3. Откройте созданного бота в Telegram и отправьте ему `/start`.
4. В терминале проекта выполните `node --env-file=.env.local scripts/telegram-chat-id.mjs`. Впишите показанный ID нужного чата в `TELEGRAM_CHAT_ID` в файле `.env.local`.
5. Перезапустите сервер разработки. После публикации задайте обе переменные окружения в настройках хостинга и разверните приложение с поддержкой серверных обработчиков Next.js.

После настройки отправьте пробную заявку с сайта и проверьте, что она пришла боту. Если у бота настроен webhook, `getUpdates` не работает; используйте ID чата, доступный в вашем обработчике webhook.

Форма ограничивает размер заявки и число отправок за 10 минут. На Vercel лимит составляет 5 заявок на IP, на других хостингах действует общий лимит 30 заявок на процесс; также есть общий предел 200 заявок на процесс. Лимиты хранятся в памяти, поэтому сбрасываются при перезапуске и не объединяются между экземплярами приложения. Для публичного сайта настройте дополнительный rate limit на уровне хостинга или WAF для `/api/contact`. На Vercel это можно сделать через Firewall → Configure → New Rule с условием Request Path и действием Rate Limit.
