# Hero → About → Vision: повторная проверка

Проверено в Playwright на Trionn при viewport 1920×907, обычной прокруткой колеса; состояние читалось после затухания Lenis. Измеренные `scrollY` ниже приблизительны для этого viewport.

| scrollY | Наблюдаемое состояние |
| ---: | --- |
| 0 | Цельный тёмный объёмный знак с отражающими гранями, медленное вращение. |
| 255 | Начало распада: несколько крупных тёмных частей отходят от центрального знака, внутри остаётся контурная структура. |
| 764 | About: закреплённый canvas всё ещё занимает viewport. В центре почти чёрный тонкий чертёж знака; крупные плоскости и мелкие осколки летают вокруг и за текстом. |
| 1359 | Конец About / начало Vision: контуры и осколки ещё в кадре, начинается строка INSPIRE / INNOVATE / IMPACT. |
| 1955 | Vision: знак собрался, виден узкий боковой ракурс. |
| 2223 | Собранный знак продолжает поворачиваться; появляются горизонтальные полосы перехода. |

DOM показал один `#trionn-symbol-canvas-wrap` внутри pin-spacer, остающийся на `y=0` во время первых трёх экранов. Это объясняет непрерывность сцены: контур и фрагменты принадлежат одной закреплённой WebGL-системе. Само вращение продолжается без прокрутки; наблюдение в Vision через несколько секунд показало другой ракурс.

Локальная реализация теперь использует один sticky canvas, scroll-прогресс в единицах высоты viewport и три фазы: распад, удержание чертежа с фрагментами, сборка. Точный шейдер/меш исходного знака не извлечён: материал и геометрия в локальном проекте процедурно приближены по видимым кадрам. Осколки темнее и многочисленнее предыдущей версии; их траектории не идентичны исходным.

## Уточнение тайминга по опубликованному JS — 22 октября

Сравнение реальной прокрутки при 1440 × 900: на scrollY около 127 знак ещё собран; около 254 уже распадается; на 382 и 510 остаются крупные объёмные пластины вместе с тонкими внутренними контурами; к 900 преобладает тёмный чертёж. Предыдущая локальная версия на 254 уже показывала почти один контур — объёмные части исчезали слишком рано.

Публичный чанк `1233qowaitufq.js` проверен как текст и отдельно разобран локальным REA CLI 6.7.0 (Evidence `ev_9dd9da3ce36116ddee18f1d13fae041171d376ac20448dcf6dd025c655ef6189`). Его runtime-формула сопоставлена с браузером: прогресс равен 0 до 0,1 высоты viewport, линейно растёт до 1 к 1,0 viewport, удерживается до 1,2 и линейно падает до 0 к 1,8. На каждом кадре состояние приближается к цели на 6%; у отдельных частей есть задержка 0–0,25 прогресса. В опубликованной сцене части и статичные края существуют одновременно; прежнее переключение локальных групп `intact → blueprint` было упрощением. При нажатии взрыв запускается после удержания около 0,5 с и только в начале Hero.

Локально применена эта шкала, более медленное сглаживание, задержка осколков и продолжение объёмных частей в переходе. Геометрия и материал остаются процедурными, поэтому кадр не идентичен источнику при одном и том же угле поворота.
